# 일상 대사 대량 집필 브리프 — «부집사 에렌의 하루»

## 세계관 · 상황
- 북부 아르젠트 대공령의 대공성(로젠하임 마을 근처). 북부는 춥고 겨울이 길다.
- 주인공 **에레나**는 남부 베르티에 남작가의 딸. 정략결혼을 피해 도망쳐 **남장**을 하고 **«에렌»**이라는 이름으로 대공성의 **부집사**로 일한다.
  - 대부분은 그녀를 남자(에렌, 부집사님)로 안다. 붕대로 가슴을 감고 다닌다.
  - 업무: 장부, 은식기 닦기, 저장고 점검, 손님 접대, 차 내오기, 심부름, 마구간·무기고·세탁장 순찰 등.
- 장소: 대공성 마당, 본관(집무실·서재·응접실·식당·주방·집사실·대공 침실·손님방), 지하 와인 저장고, 서쪽 별관(하인 숙소·부집사 방), 세탁장, 동쪽 별관, 동관 온실, 기사단 숙소·훈련장, 무기고, 마구간, 로젠하임 마을(광장·분수·시장·호수·공원·찻집·빵집·서점·꽃집·잡화점·양장점), 하겐 상회, 선술집 «검은 곰».
- 계절: 봄·여름·가을·겨울(28일씩). 날씨: 맑음, 비, 눈, 눈보라.

## 인물과 말투 (기존 대사는 `ref_lines.js` 참고 — 반드시 먼저 읽고 말투를 맞출 것)
- **카이런 아르젠트** (대공, 공략 대상): 냉정·과묵·짧은 명령조 반말. 속으로는 다정해서 행동으로 챙김(연고, 담요, 식사). 귀 끝이 붉어지는 식의 묘사. 부를 때 «에렌». 정체를 안 뒤 둘만 있을 땐 «에레나».
- **로웬** (기사단장, 공략 대상): 밝고 장난스러운 반말, 허세, 술·외상. 에렌을 «꼬마»라 부름. 정 많고 의리 있음.
- **에드먼드** (노집사): 정중한 존댓말, «부집사님». 차·예법·성의 역사에 밝다. 은근한 유머, 카이런을 어릴 때부터 모심.
- **마르타** (하녀장): 시원시원·잔소리 반말, «꼬맹아/꼬마». 빨래·청소. 눈치 빠름(정체를 일찍 눈치챔).
- **브란트** (주방장, 여성, 대사에선 다들 «브란트 아저씨»라 부르는 농담이 있음 — 기존 대사 참고): 무뚝뚝하고 거친 말투, 먹는 걸로 챙김.
- **팀** (고아 소년, 마구간 일 돕는 아이): 해맑은 존댓말, 에렌을 «형»이라 부름(정체가 공개되면 «누나»).
- **데미안** (기사, 과묵): «……»로 시작하는 짧은 존댓말, «부집사님». 카이런의 명으로 에렌을 지킴.
- **세실리아** (귀족 영애, 경쟁자): 새침·도도한 반말, «꼬맹이 부집사». 츤데레 기미.
- **에레나(플레이어, M)**: 존댓말(어른들에게), 당황하면 말 더듬음. 속마음은 괄호 «(…)».

## 출력 형식 (반드시 이 JSON 그대로, 파일 하나에 담당 인물 전부)
```json
{
  "kairan": [
    {"k":"kai_rain_ledger", "tier":0, "cond":{"weather":"rain"},
     "s":[["n","n","비 오는 날엔 장부가 눅눅해진다. 서재에 둬라."],
          ["m","s","네, 전하!"],
          ["r","그는 고개도 들지 않았지만, 서재 난로엔 이미 불이 지펴져 있었다."]]}
  ]
}
```
- `k`: 고유 키(영문 소문자·숫자·밑줄, 인물 접두어). 파일 안에서 중복 금지.
- `tier`: 호감 단계. 0 = 처음~서먹(하트 0~2), 1 = 친해짐(3~5), 2 = 아주 가까움(6+). 단계마다 고르게.
- `cond` (모두 선택, 없으면 `{}`):
  - `season`: "봄"|"여름"|"가을"|"겨울"
  - `weather`: "clear"|"rain"|"snow"|"blizzard"
  - `time`: "morning"(6–11시)|"afternoon"(11–17시)|"evening"(17시~)
  - `sunday`: true (휴무일)
  - `known`: true → 상대가 에레나가 여자인 걸 알게 된 뒤에만(정체를 아는 대사). 이 표시가 없으면 **남장 중에도 자연스러워야 함**(«에렌», 남자로 대함).
  - `lover`: true → 연인/약혼/결혼 상태에서만 (카이런·로웬만).
- `s`: 대사 줄 배열. 각 줄은
  - `["n", 표정, "대사"]` — 상대 인물(NPC)
  - `["m", 표정, "대사"]` — 에레나
  - `["r", "서술"]` — 지문/속마음 서술
  - `["c", [ {"t":"선택지 문구", "p":0~30(호감), "r":[ ...줄 배열... ]}, ... ]]` — 선택지 2~3개 (대사 묶음 중 4개에 1개 정도만)
  - 표정: `n` 보통, `h` 웃음/기쁨, `a` 짜증/곤란, `b` 부끄러움/설렘, `s` 놀람/당황
- 한 묶음은 2~6줄. 한 줄은 60자 이내.

## 질 · 다양성 요구
- 같은 소재 반복 금지. 업무, 성 생활, 계절·날씨, 음식, 말, 훈련, 책, 과거 이야기, 다른 인물 이야기(소문·뒷담·칭찬), 장난, 걱정, 작은 사건, 설렘 등 골고루.
- tier가 올라갈수록 거리감이 줄고 감정이 묻어나게. tier 2와 `lover`는 설레는 장면 위주(노골적 묘사 금지).
- 매일 다른 인상을 주도록 짧은 일화·디테일을 넣을 것. 원작 플롯 사건(고백, 정체 발각 등)은 직접 다루지 말 것.
- 맞춤법·띄어쓰기 정확히. 따옴표 안에 « » 사용 가능.

## 분량 (반드시 채울 것)
담당 인물별 지정 개수. 계절·날씨·시간 조건 묶음을 전체의 40% 정도로.
