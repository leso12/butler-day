# 데이트 재집필 브리프 — «부집사 에렌의 하루»

먼저 읽을 것: `BRIEF.md`(세계관·말투), `ref_lines.js`(기존 대사), `ref_dates.js`(지금의 데이트 — 짧음, 이를 대체), `locs.txt`(장소 id).

## 목표
데이트를 "작은 단편 영화"처럼. 지금은 3~7줄짜리라 밋밋하다.
- 각 데이트 변형(variant)은 **20~32줄**, 장면 전환 2~3번(도착 → 사건/대화 → 여운).
- 오감 묘사(바람, 냄새, 소리), 상대의 사소한 버릇·행동, 설렘 포인트(손끝, 시선, 겉옷) — 과하지 않게.
- **선택지 2개 이상**(각 2~3지), 선택에 따라 2~5줄 다른 반응 (p: 호감 10~60, to: 상대 id).
- 같은 데이트를 다시 가면 다른 이야기: 변형 수만큼 **완전히 다른 전개**.
  - 변형 1: 처음 (서먹하거나 설렘 시작) · 변형 2: 익숙해짐 · 변형 3(있으면): 아주 가까움/연인 느낌
- 정체(에레나가 여자)는 아직 비밀일 수도 있다 → 상대가 아는 듯한 대사는 `{"known":true}` 변형으로만. 기본 변형은 남장 «에렌»으로 자연스러워야 함. (카이런·로웬 연인 전용 데이트(rom:1)는 정체를 안다고 가정해도 됨.)
- 노골적 묘사 금지. 원작 플롯 사건(고백, 정체 발각)은 직접 다루지 말 것.

## 출력 형식 (JSON)
```json
{"kairan":[
  {"k":"tea","name":"서재의 차 시간","rom":0,"loc":"library","hour":20,"pose":"tea",
   "variants":[
     {"lines":[["r","— 서재의 차 시간 —"],["r","서술"],["x","kairan","n","대사"],["m","b","에레나"],
               ["c",[{"t":"선택지","p":40,"to":"kairan","r":[["x","kairan","h","반응"]]},{"t":"…","p":20,"to":"kairan","r":[...]}]]]},
     {"lines":[...]},
     {"known":true,"lines":[...]}
   ]}
]}
```
- 줄: `["r","서술"]`, `["m",표정,"에레나"]`, `["x",인물id,표정,"대사"]`, `["g","이름","마을 사람"]`, `["c",[선택지]]`. 표정 n/h/a/b/s.
- `k`: 기존 데이트는 같은 k 유지(ref_dates.js 참고). 새 데이트는 새 k(영문 소문자).
- `loc`: locs.txt의 장소 id. `hour`: 시작 시각(정수 6~22). `rom`: 1이면 연인 전용.
- `pose`: 연출 — "tea"(마주 앉아 차/체스/뜨개질/술), "hold"(나란히 걷기·손잡기), "cook"(나란히 요리), ""(없음).
- 각 변형 첫 줄은 `["r","— 제목 —"]`.
- 한 줄 70자 이내, 맞춤법 정확히.

검증: `python3 -c "import json;d=json.load(open(파일));print({k:[(x['k'],len(x['variants']),[len(v['lines']) for v in x['variants']]) for x in v] for k,v in d.items()})"`
